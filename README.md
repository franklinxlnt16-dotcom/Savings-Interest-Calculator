# Savings & Interest Calculator

## Project Overview

This project is a Python-based Savings & Interest Calculator created as a hands-on exercise in my Python learning journey.

The program allows users to enter savings information and calculates the growth of their savings over time using interest calculations.

## Python Concepts Practiced

- Variables and data types
- User input
- Arithmetic operators
- Comparison and logical operators
- Conditional statements
- For loops
- While loops
- Functions
- Parameters and arguments
- Return values
- Local and global variables
- Input validation

## Project Features

- Accepts user input
- Performs savings and interest calculations
- Processes savings over time
- Uses conditional logic and loops
- Displays a savings report
